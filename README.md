## 📌 About
This project explores **THC-Hydra**, an open-source network login auditing tool used to assess password security and identify weaknesses in authentication systems.
The project covers Hydra's features, installation, comparison with other security tools, and practical demonstrations of authentication testing using HTTP POST, SSH, MariaDB, FTP, VNC, and POP3 in controlled lab environments.

## 🎯 Objectives
- Explore Hydra's features and applications in ethical hacking.
- Compare Hydra with other cybersecurity tools.
- Demonstrate authentication testing in authorized environments.
- Understand Hydra's limitations and security implications.

## 🛠️ Tools Used
- Kali Linux
- THC-Hydra and Xhydra
- VirtualBox / VMware
- TryHackMe and OpenVPN
- MariaDB, vsftpd, Dovecot, SSH, and VNC
